# Project Overview: "The Rebirth H22" Portal

## What is this Portal?

This portal is a private, web-based project management and digital asset library, built specifically for the "The Rebirth H22" creative project. It acts as a central hub for the entire team to organize, view, and collaborate on all aspects of the project, from initial ideas to final 3D models.

## Why Was It Built?

The main goal is to help manage the project's complexity by:

* **Centralizing Assets:** Creating a single, reliable place for every file, including 3D models, concept art, scripts, and notes. This means no more searching through different folders or drives.
* **Streamlining Collaboration:** Allowing team members to work together smoothly, see updates in real-time, and leave feedback directly on project items.
* **Visualizing the Project:** Providing powerful tools to see how different parts of the project—like characters, scenes, and chapters—all connect to each other.

## Who Is It For?

The platform is designed for the core creative team, with different roles to manage access:
* **Admins:** Have full control.
* **Editors:** Can create and edit content like characters and scenes.
* **Viewers:** Can see everything and leave comments, but cannot make changes.
