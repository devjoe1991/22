Tech Stack for "The Rebirth H22"
Category

Technology

Justification

Frontend Framework

Next.js (App Router)

Provides hybrid rendering (SSR/SSG/CSR), a robust file-based router, and server components for a performant and scalable architecture.

Backend & Database

Supabase

An all-in-one BaaS that includes a PostgreSQL DB, Auth, Storage, and Realtime subscriptions, massively accelerating backend development.

Styling

Tailwind CSS

A utility-first CSS framework for rapidly building modern, custom designs without leaving the HTML.

Component Library

Shadcn/UI & Aceternity UI

Provides beautifully designed, unstyled, accessible components (Shadcn) and advanced animated components (Aceternity) that are highly customizable.

Icons

Lucide Icons

A clean, extensive, and lightweight icon library that integrates perfectly with React.

State Management

Zustand / Jotai

Lightweight, powerful global state management solutions that are simpler than Redux and ideal for managing cross-component state.

Drag & Drop

dnd-kit

A modern, performant, and accessible library for building rich drag-and-drop interfaces.

Forms

React Hook Form

The industry standard for creating performant, flexible, and scalable forms in React.

Rich Text Editing

Tiptap

A headless, extensible rich text editor, perfect for building a custom, collaborative text editing experience.

Visual Workflows

React Flow

A powerful library for building interactive, node-based editors and diagrams, ideal for the workflow and mood board features.

3D Rendering

React Three Fiber & Drei

A React renderer for Three.js that simplifies the process of creating and managing 3D scenes in a declarative way.

Deployment

Vercel

The native hosting platform for Next.js, offering seamless Git integration, automatic deployments, and global CDN.
