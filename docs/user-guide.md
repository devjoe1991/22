# User Guide: Getting Started with the Portal

Welcome to "The Rebirth H22" project portal! This guide will walk you through the most common tasks.

### 1. Creating Content (For Editors)

The first step is to populate the world with its core entities.

1.  **Navigate to a Directory:** Use the sidebar to go to `Characters`, `Scenes`, or `Chapters`.
2.  **Create an Item:** Click the `Create Character` (or Scene/Chapter) button in the top-right corner.
3.  **Add Details:** You will be taken to a new page for that item. Fill in the name and use the rich text editor to add a detailed description. Your work is saved automatically.

### 2. Linking Your Content (The Core Workflow)

This is the most powerful feature of the portal. Here's how to "tag" a Character to a Scene. (The same process works for linking Scenes to Chapters).

1.  **Navigate to a Scene:** Go to the `Scenes` directory and click on the Scene you want to add a character to.
2.  **Find the Tagging Section:** On the scene's detail page, look for the section titled "Characters in this Scene".
3.  **Select and Add:** Use the dropdown menu to find the Character you want to link. Click the `Add Character` button.
4.  **It's Linked!** The character will now appear in the list. If you navigate to that Character's page, you will see this Scene listed as one of its appearances.

### 3. Uploading Files & Assets

Each Character, Scene, etc., has its own asset gallery for storing related files like concept art, 3D models, or reference images.

1.  **Go to an Item's Detail Page.**
2.  **Find the Asset Gallery:** Look for the drag-and-drop file upload area.
3.  **Upload:** Drag files from your computer directly onto the upload zone. You will see a progress bar, and the file will appear in the gallery once the upload is complete.

### 4. Visualizing the Project

To see how everything connects:

1.  **Navigate to `Workflows`** using the sidebar.
2.  Here you will find a list of visual diagrams. Click on one to open the interactive canvas.
3.  This canvas reads all the links you've made and displays them as a connected map of your project.

### 5. Collaborating (For All Users)

Every detail page has tools for discussion.

* **Leaving Comments:** At the bottom of any item's page, you'll find a comment section. Simply type your feedback and submit.
* **Real-Time Updates:** The portal is real-time. If another user comments on an item you're viewing, their comment will appear instantly without a page refresh. You will also receive a notification in the header bell icon.
